UNIT 01Fix the bugTUPLE vs LIST

A teacher wants to update the first score in a leaderboard. Running this crashes with a red error.

unit01_leaderboard.py
# Update the top score after a re-markscores = (90, 85, 70)scores[0] = 100print(scores)
Your task: Read the error message. Why won't the value change? Fix the script so the output becomes [100, 85, 70].
⚷ Answer Key · Unit 01

THE FAULTscores is built with round brackets, making it a tuple — which is locked. Line 3 tries to change slot 0, but tuples don't support item assignment.

ERROR SHOWNTypeError: 'tuple' object does not support item assignment

THE FIXChange the round brackets to square brackets so it's a list: scores = [90, 85, 70]

CORRECT OUTPUT

[100, 85, 70]
UNIT 02Predict outputLOOP · CONTINUE · ACCUMULATOR

This script runs perfectly. Trace it carefully — watch what continue does.

unit02_skip_sum.py
total = 0for n in range(1, 6):    if n == 3:        continue    total = total + nprint(total)
Your task: What single number does this print? Write down what range(1, 6) produces and which value gets skipped.
⚷ Answer Key · Unit 02

THE TRACErange(1, 6) gives 1, 2, 3, 4, 5 (stops before 6). When n == 3, continue skips the rest of that loop, so 3 is not added.

THE MATH1 + 2 + 4 + 5 = 12. The print is outside the loop, so it only prints once at the end.

CORRECT OUTPUT

12

COMMON WRONG ANSWERS15 (forgot to skip 3), or four separate lines (thought print was inside the loop).

UNIT 03Fix the bugSET · NO INDEXING

A student wants to read the first colour from a set. It crashes.

unit03_colours.py
colours = {"red", "green", "blue"}# Check if "green" is in the set, then list them allprint(colours[0])
Your task: Why can't you use [0] on a set? Fix line 3 so the script instead checks whether "green" is in the set (should print True).
⚷ Answer Key · Unit 03

THE FAULTSets are unordered — there's no "slot 0", so you can't index them with [0].

ERROR SHOWNTypeError: 'set' object is not subscriptable

THE FIXUse the in keyword to test membership: print("green" in colours). (To see every item instead, loop: for c in colours: print(c).)

CORRECT OUTPUT

True
